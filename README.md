
# CONSOLE BASE

**PlayStation 4 Archive**

CONSOLE BASE — независимый каталог материалов для PlayStation 4.

## Разделы

- Обновления
- Прошивки PS4
- Приложения
- Игры для PS4
- Файлы

## Возможности

- Современный тёмный дизайн
- Поиск по каталогу
- Фильтрация по категориям
- Карточки материалов
- Всплывающие окна с информацией
- Адаптация для мобильных устройств
